# First-Project: Expense-Tracker

This has been my first learning project to apply my theoretical knowledge as a computer science student at the University of Augsburg. 
It is a simple Transaction Manager that was initially designed as a console-based application and late  upgraded wit a Graphical User Interface. To ensure clean and maintainable code, I structured the application using the MVC pattern.
It is built wiht Java and JavaFX, and compiled using Maven.
